# One Board One Deck

一個棋盤，一副牌。乾淨、不眼花的小遊戲合集。

- 撲克牌：**大老二**（你對 3 個電腦）
- 棋盤：**五子棋**（你對 1 個電腦）

沒有廣告、沒有內購、不蒐集資料，離線可玩。

## 線上預覽

推送到 `main` 後會自動部署到 GitHub Pages：
<https://archie-30.github.io/one-board-one-deck/>

第一次使用需要到 GitHub 專案的 **Settings → Pages → Source** 選擇 **GitHub Actions**。

## 本機指令

| 指令 | 用途 |
| --- | --- |
| `npm install` | 安裝套件 |
| `npm run dev` | 本機開發 |
| `npm run test` | 跑規則引擎測試 |
| `npm run build` | 建置網頁版到 `dist/` |

專案規則與架構請看 [CLAUDE.md](./CLAUDE.md)，版本紀錄請看 [更新日誌.md](./更新日誌.md)。
